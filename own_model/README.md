# Собственная модель с нуля

Этот каталог содержит минимальный воспроизводимый pipeline для обучения небольшой decoder-only языковой модели **без готовых весов и без платного API**. Модель использует только PyTorch и byte-level UTF-8 токенизацию, поэтому её словарь создаётся прямо в проекте.

> Это учебный MVP, а не модель уровня коммерческого универсального ассистента. При нулевом бюджете разумная стратегия — обучить компактную модель, а затем добавлять качество через собственные данные, память, поиск и инструменты.

## Быстрая проверка

```bash
python3 -m pip install torch
python3 own_model/train.py \
  --text own_model/data/corpus.txt \
  --steps 50 \
  --batch-size 4 \
  --block-size 128 \
  --out own_model/checkpoints/tiny-gpt.pt

python3 own_model/generate.py \
  --checkpoint own_model/checkpoints/tiny-gpt.pt \
  --prompt "Пользователь: Как начать проект?\nАссистент:"
```

Для серьёзного эксперимента корпус нужно расширить лицензированными открытыми текстами, диалогами и примерами задач. Не загружай персональные данные и не копируй материалы, для которых нет права на использование.

## Бесплатное обучение

Обучение можно запускать в Google Colab как интерактивный notebook. Бесплатные GPU не гарантированы, сессии могут завершаться, поэтому checkpoint сохраняй во внешнее хранилище после каждого evaluation interval. Не используй Colab как постоянный веб-сервер.

Параметры по умолчанию дают модель порядка нескольких миллионов параметров. Для первого теста используй маленькие `--steps`, затем увеличивай корпус, `--steps` и размер модели только после проверки loss и генерации.

## Размещение на Render

Render Free подходит для лёгкого API или Telegram-бота, но не для обучения. Его файловая система эфемерна, поэтому checkpoint и пользовательскую память нельзя считать надёжно сохранёнными в локальных файлах. На Render следует либо упаковывать небольшой checkpoint в deploy artifact, либо подключать внешнее постоянное хранилище. Модель должна быть достаточно компактной для доступной памяти сервиса.

## Следующий технический шаг

После проверки обучения нужно добавить `local` AI provider в `ai.py`, который будет вызывать inference-сервис собственной модели. Для production-режима лучше разделить Telegram-бота и inference: Render запускает бота, а модель работает в отдельном доступном пользователю процессе или вызывается только в режиме fallback. Это не заменяет полноценное дообучение и оценку качества.
