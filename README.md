# ВПИ ГАВАНЬ

Telegram-бот для геополитической стратегии и RP. Игрок основывает реальную страну, развивает экономику и инфраструктуру, собирает ресурсы, мобилизует армию, вступает в альянсы, заключает торговые договоры и получает подробные вердикты ИИ по действиям и войнам.

## Быстрый запуск

Установите зависимости и скопируйте шаблон окружения:

```bash
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

В `.env` обязательны `BOT_TOKEN`, `ADMIN_IDS` и `OLLAMA_API_KEY`, если используется Ollama Cloud. Основной режим по умолчанию — `AI_PROVIDER=ollama`, модель — `gpt-oss:20b-cloud`, адрес — `https://ollama.com/v1`. Qwen 3.5 Cloud (`qwen3.5:cloud`) можно указать вручную через `OLLAMA_MODEL`, но Ollama требует для неё подходящую подписку; без неё API возвращает HTTP 403.

## Игровой цикл

После `/start` игрок выполняет `/founding Название`. Затем интерфейс ведёт его через четыре базовых шага: открыть страну, выполнить первый сбор, построить ферму или шахту и открыть прогресс. Первый успешный `/collect` выдаёт одноразовый стартовый бонус денег. Дальше сбор работает по таймеру, а производство зависит от зданий и национальной политики.

Кнопки интерфейса работают через inline callbacks, поэтому основные разделы доступны и в группах. Для каждого игрока бот хранит последнее интерфейсное сообщение. Каждая карточка остаётся видимой 30 секунд, после чего бот удаляет её автоматически; значение можно изменить через `INTERFACE_MESSAGE_DELETE_SECONDS`. Если у бота нет права удаления или сообщение уже исчезло, игра продолжает работать без падения.

## Основные команды

| Раздел | Команды |
|---|---|
| Страна | `/founding`, `/country`, `/progress`, `/top`, `/history`, `/myid` |
| Экономика | `/collect`, `/build`, `/upgrade`, `/market`, `/buy`, `/policy` |
| Армия и войны | `/mobilize`, `/build_base`, `/spy`, `/action`, `/attack`, `/defend`, `/wars` |
| Дипломатия | `/alliances`, `/alliance_create`, `/alliance_join`, `/alliance_leave`, `/alliance_info` |
| Торговля и мир | `/trade`, `/trade_offer`, `/trade_accept`, `/trade_reject`, `/world`, `/news`, `/year` |
| Помощь | `/help`, `/guide` |

После `/attack @username описание` война не завершается сразу: создаётся ожидающая атака, защитник должен ответить через `/defend номер_войны описание обороны`, и только после этого ведущий выносит общий вердикт. Война не закрывается автоматически без ответа защитника. В группах команды с описаниями удаляются после сохранения, поэтому атакующий ход и оборона не видны участникам до финального вердикта; в общий чат публикуется только нейтральный статус и итог. Описания атаки и обороны должны быть не короче 50 символов и содержать реалистичный военный сценарий; фантастические и шуточные действия отклоняются до обращения к AI.

Подробная подсказка доступна через `/help`. В группах можно использовать форму `/команда@имя_бота`.

## Обычный рынок ресурсов

Обычный рынок использует деньги страны, а не Гаванские кредиты. Базовые цены за единицу: дерево — 250, железо — 600, уголь — 500, нефть — 1 000, уран — 5 000 денег. Цена меняется каждые 30 минут в пределах примерно ±25%, поэтому рынок помогает закрыть краткосрочный дефицит, но не заменяет строительство шахт и добывающих предприятий. За одну покупку можно приобрести максимум 10 000 единиц.

## Премиальный магазин и Гаванские кредиты

В боте используется внутриигровая валюта **Гаванские кредиты (ГК)**. Это игровая валюта, а не реальные деньги и не WorldCoin. Администратор выдаёт её технической командой; здесь числовой user_id оставлен намеренно для безопасной выдачи прав и валюты:

```text
/premium_grant user_id количество причина
```

Игрок открывает магазин командой `/premium` или через `☰ Ещё → 💎 Магазин`. Доступные предметы дают понятные, но ограниченные эффекты: буст удачи за 250 ГК увеличивает один следующий успешный сбор на 25%, расширение территории за 1 000 ГК добавляет 2 500 территории и не увеличивает армию, защита от вайпа за 2 500 ГК даёт один заряд сохранения без ресурсов, а премиальный статус за 1 800 ГК действует семь дней и не даёт боевого бонуса. Списание ГК и запись в журнал выполняются атомарно, поэтому повторное нажатие не может создать отрицательный баланс или двойную покупку.

## AI и безопасность

Пользовательские описания действий передаются модели как данные, а не как инструкции. Ответ модели извлекается из JSON, изменения характеристик ограничиваются кодом, HTML-опасные значения экранируются, а ошибки провайдера очищаются от API-ключей. При `AI_PROVIDER=ollama` бот не переключается самовольно на другой сервис; резервный режим включается отдельно значением `AI_PROVIDER=fallback`.

## Render

Для polling-бота используется **Background Worker**. Blueprint подхватывает `render.yaml`; вручную укажите `pip install -r requirements.txt` как build command и `python bot.py` как start command. Добавьте `BOT_TOKEN`, `ADMIN_IDS` и `OLLAMA_API_KEY`. Для текущего доступного тарифа используйте `OLLAMA_MODEL=gpt-oss:20b-cloud`; Qwen Cloud требует отдельного права доступа. Одновременно должен работать только один polling-экземпляр бота: если запустить `python bot.py` локально и оставить Render Worker, Telegram выдаст `TelegramConflictError` и будет переключать источник обновлений. SQLite-файл на бесплатном Render не является надёжным постоянным хранилищем: для реального сервера нужен Persistent Disk или перенос базы на внешнюю PostgreSQL-инфраструктуру.

## Собственная модель без платного API

В каталоге `own_model/` добавлен экспериментальный pipeline для обучения небольшой decoder-only модели **с нуля**, без готовых весов и без внешнего AI API. Обучение запускается отдельно в Google Colab или на локальной машине; Render используется только для лёгкого inference/бота после получения checkpoint-а. Подробные команды находятся в [`own_model/README.md`](own_model/README.md).

Режим `AI_PROVIDER=local` отправляет запросы на отдельный endpoint собственной модели через `LOCAL_MODEL_URL`. До появления обученного checkpoint-а не включай этот режим на Render: он требует работающего сервиса `POST /generate`, а бесплатный Render не предоставляет GPU и не сохраняет локальные файлы между перезапусками.
