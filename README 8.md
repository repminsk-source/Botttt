# ВПИ ГАВАНЬ — бот

Telegram-бот для геополитической RP-игры: страны, экономика, постройки, армия, вердикты по действиям через ИИ.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:
- `BOT_TOKEN` — получить у [@BotFather](https://t.me/BotFather)
- `GROK_API_KEY` — получить на [console.x.ai](https://console.x.ai) (основная модель, платная — есть бесплатные кредиты для новых аккаунтов)
- `GEMINI_API_KEY` — получить на [aistudio.google.com/apikey](https://aistudio.google.com/apikey) (бесплатно, резервная модель на случай если Grok недоступен)
- `ADMIN_IDS` — твой telegram user_id (узнать через /myid у бота)

## Запуск

```bash
python bot.py
```

## Игровая механика

### Характеристики страны
Economy, military, population, tech, diplomacy — абстрактная "сила" страны, используется в вердиктах ИИ
и в рейтинге /top. Качаются через `/upgrade` за очки развития (начисляет админ через `/give_points`).

**Экономика прокачивается дороже с каждым уровнем** — цена не фиксированная, а растёт:
цена N-го пункта = `ECONOMY_BASE_COST + текущий_уровень * ECONOMY_COST_STEP` (по умолчанию 3, потом 4, 5, 6...).
Настраивается в `config.py`.

**Армия качается отдельно** — не через `/upgrade`, а через `/mobilize`: требует резерв людей (manpower)
и золото (см. ниже).

### Ресурсы и постройки
У каждой страны есть четыре ресурса: 💰 золото, 📦 ресурсы, 🧑‍🤝‍🧑 резерв людей, 🌽 еда (плюс 💧 вода).
Чтобы их получать — нужно строить:

| Постройка | Даёт | Команда |
|---|---|---|
| 🌾 Ферма (farm) | резерв людей | `/build farm` |
| ⛏️ Шахта (mine) | ресурсы | `/build mine` |
| 🏪 Рынок (market) | золото | `/build market` |
| 💧 Колодец (well) | вода | `/build well` |
| 🌽 Амбар (granary) | еда | `/build granary` |

Каждый уровень постройки стоит дороже предыдущего (цена растёт линейно с уровнем).

**`/collect`** — сбор ресурсов со всех построек, доступен раз в **45 минут**
(настраивается `COLLECT_COOLDOWN_SECONDS` в `.env`, по умолчанию 2700 сек).
При каждом сборе экономика страны также **немного растёт сама** — прибавка зависит от уровня
шахты и рынка (`(mine_level + market_level) // ECONOMY_GROWTH_DIVISOR`), то есть развитая
экономическая инфраструктура постепенно повышает силу экономики без ручной прокачки.
Накопленная **еда** сверх порога (`FOOD_GROWTH_THRESHOLD`, по умолчанию 50) при каждом `/collect`
автоматически конвертируется в рост населения (+1 population за каждый порог) — еда тратится.

**`/mobilize количество`** — превращает резерв людей + золото в военную мощь (military).
Стоимость 1 пункта армии — `MOBILIZE_MANPOWER_PER_POINT` резерва и `MOBILIZE_GOLD_PER_POINT` золота
(по умолчанию 10 и 15). То есть чтобы усилить армию, нужно сначала настроить экономику и накопить
достаточно людей и денег — просто так очками военные не прокачать.

### Войны между игроками

**`/attack user_id описание`** — атака чужой страны. ИИ выносит вердикт по исходу столкновения,
учитывая характеристики (в первую очередь армию) обеих сторон, и правит `stat_changes` обеим
странам. Победитель забирает `WAR_LOOT_PERCENT` % золота и ресурсов проигравшего (по умолчанию 20%),
при ничьей трофеев нет. Между атаками действует кулдаун `ATTACK_COOLDOWN_SECONDS` (по умолчанию 1 час).
`/wars` — лента последних столкновений.

### Стартовые значения
При `/founding` страна получает: все характеристики по 10, 💰50 золота, 📦30 ресурсов,
🧑‍🤝‍🧑20 резерва людей, 💧25 воды, 🌽40 еды, 0 построек, 0 очков развития. Значения — в `config.py`
(`START_STATS`, `START_GOLD`, `START_RESOURCES`, `START_MANPOWER`, `START_WATER`, `START_FOOD`).

## Команды

Всё в одном месте — `/help` (для админов показывает ещё и админский блок).

| Команда | Описание |
|---|---|
| `/founding Название` | Основать страну |
| `/country` | Характеристики + ресурсы + постройки одним сообщением |
| `/top` | Рейтинг стран по суммарной силе |
| `/upgrade экономика количество` | Прокачать economy/population/tech/diplomacy за очки развития |
| `/build тип` | Построить/улучшить ферму, шахту, рынок, колодец или амбар |
| `/collect` | Собрать ресурсы с построек (раз в 45 мин) |
| `/mobilize количество` | Прокачать армию за резерв людей + золото |
| `/action описание` | Совершить действие — вердикт от ИИ, меняет характеристики |
| `/attack user_id описание` | Атаковать другого игрока — вердикт от ИИ решает исход войны |
| `/wars` | Последние военные столкновения |
| `/news` | Последние события мира |
| `/myid` | Узнать свой telegram user_id |

Между вызовами `/action` действует кулдаун (по умолчанию 30 мин, `ACTION_COOLDOWN_SECONDS`).
Между вызовами `/attack` — свой кулдаун (по умолчанию 1 час, `ATTACK_COOLDOWN_SECONDS`).

Админские:

| Команда | Описание |
|---|---|
| `/give_points [user_id] количество` | Начислить очки развития всем или одному игроку |
| `/set_stat user_id характеристика значение` | Ручная корректировка характеристики |
| `/kick user_id` | Убрать игрока со страны (удаляет страну) |
| `/transfer старый_id новый_id` | Передать страну другому аккаунту |

## Как устроены вердикты

При `/action` бот шлёт запрос к Grok (модель `grok-4.3`, xAI) с системным промптом,
описывающим правила мира и характеристики страны игрока. Если Grok недоступен — fallback на
Gemini 2.0 Flash. Модель обязана вернуть JSON с текстом вердикта и изменениями характеристик, бот
парсит его и обновляет базу (изменение каждой характеристики дополнительно жёстко ограничено ±5
в коде, независимо от того, что вернула модель). Промпт — в `ai.py` (`SYSTEM_PROMPT`), стоит
доработать под лор мира.

При `/attack` используется отдельный промпт (`WAR_SYSTEM_PROMPT`), который получает характеристики
обеих сторон и возвращает вердикт с изменениями характеристик для нападающего и обороняющегося
(ограничение ±8 в коде).

Весь текст, приходящий от игроков (название страны, описание действия/атаки) и от ИИ (текст
вердикта), экранируется перед вставкой в HTML-сообщения Telegram — иначе символы `<`, `>`, `&`
в названии страны или в ответе модели ломают разметку и бот не может отправить сообщение.

## Надёжность

- SQLite работает в режиме **WAL** с `busy_timeout=30s` — при параллельных командах разных игроков
  соединения не падают сразу с "database is locked", а дожидаются освобождения блокировки.
- В боте есть глобальный обработчик ошибок (`@dp.error()`): необработанное исключение в любой
  команде логируется с трейсбеком и не остаётся незамеченным, а пользователь получает сообщение
  об ошибке вместо молчания.
- Блокировки на пользователя (`asyncio.Lock`) защищают от гонки при быстром повторном вызове одной
  команды. Для `/attack`, где участвуют два игрока сразу, оба лока берутся в фиксированном порядке
  (по возрастанию user_id), чтобы встречные одновременные атаки не привели к deadlock.
- Применение результата `/attack` (изменения характеристик обеих сторон + трофеи) выполняется одной
  транзакцией — исключает частичное применение при сбое посередине.

## Хостинг на Render

Разворачивать как **Background Worker** (не Web Service — polling-боту открытый порт не нужен).

1. Залей код в GitHub-репозиторий.
2. Render → **New → Blueprint**, укажи репозиторий (подхватит `render.yaml`).
   Либо вручную: **New → Background Worker**, build `pip install -r requirements.txt`, start `python bot.py`.
3. Добавь переменные окружения в панели сервиса: `BOT_TOKEN`, `GROK_API_KEY`, `GEMINI_API_KEY`, `ADMIN_IDS`.
4. Деплой.

**⚠️ Бесплатный тариф Render не даёт персистентный диск** — `gavan.db` стирается при каждом деплое/рестарте.
Варианты: смириться (для теста), платный план с Persistent Disk (раскомментируй `disk` в `render.yaml`),
либо вынести на внешний Postgres (Render/Supabase/Neon есть бесплатные тиры — могу переписать `db.py` под это).

Если решишь запускать как Web Service — в `bot.py` есть заглушка health-check сервера, активируется
переменной `RENDER_WEB_SERVICE=1`.

## Реальные страны и территория

`/founding` принимает **только реально существующие страны мира** (список в `countries.py`,
с алиасами вроде «США»/«сша»/«usa» или «Кот-д'Ивуар»/«Кот-д Ивуар» — распознаются как одна
страна). Придуманные названия отклоняются. Каждая страна занята только одним игроком одновременно.

Территория (`territory.py`, три уровня: small/medium/large, определяется автоматически по
реальной площади) ограничивает:
- максимум `population` (`TERRITORY_POPULATION_CAP` в `config.py`),
- максимальный уровень добывающих построек, включая нефтевышки (`TERRITORY_BUILDING_LEVEL_CAP`),
- бонус к числу военных баз (`TERRITORY_BASE_BONUS`).

## Ресурсы и заводы

Кроме золота/ресурсов/резерва людей/воды/еды есть 4 сырьевых ресурса — 🌲 дерево, ⛓️ железо,
🪨 уголь, 🛢️ нефть. Каждый добывается своей постройкой (`sawmill`, `iron_mine`, `coal_mine`,
`oil_rig` — строятся через `/build`, как и старые). Любой из них можно также напрямую **купить
за золото** — `/buy ресурс количество` (цены — `RESOURCE_BUY_PRICE_GOLD` в `config.py`).

## Военные базы

`/build_base` — база стоит золото+ресурсы (растёт с числом уже построенных). Максимум баз =
бонус от территории + `military // MILITARY_PER_BASE`, то есть чем сильнее армия, тем больше
баз можно построить (а не наоборот) — сильная небольшая страна не будет искусственно ограничена.

## Шпионаж

`/spy user_id` — скрытная разведка: цель **никогда не получает уведомление**, ни при успехе,
ни при провале. Шанс успеха зависит от разницы tech/diplomacy шпиона и цели. При успехе шпион
получает характеристики цели, при провале — ничего. Кулдаун `SPY_COOLDOWN_SECONDS` (по умолчанию
90 мин), стоимость `SPY_COST_GOLD`.

## Альянсы

`/alliance_create ТЕГ Название` — создать; `/alliance_join ТЕГ` — вступить; `/alliance_leave` —
выйти; `/alliance_info [ТЕГ]` — состав; `/alliances` — список всех. Игрок состоит максимум в
одном альянсе одновременно. Админ может сразу после вайпа поднять «канонические» альянсы
(НАТО, ОДКБ, ЕС, ШОС — список в `CANONICAL_ALLIANCES`) командой `/seed_alliances`.
